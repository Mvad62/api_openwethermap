# Приложение погоды

Консольное приложение получает текущую погоду в городе или по географическим
координатам через API OpenWeather. Температура отображается в градусах Цельсия,
описание погоды — на русском языке.

## Требования

- Python 3.10 или новее
- API-ключ OpenWeather с доступом к Geocoding API и Current Weather API

## Установка

В PowerShell из папки проекта выполните:

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Создайте в корне проекта файл `.env` и укажите в нём свой ключ:

```dotenv
API_KEY=ваш_ключ_openweathermap
```

Не добавляйте `.env` в систему контроля версий: файл с ключом уже исключён
через `.gitignore`.

## Запуск

```powershell
python weather_app.py
```

В меню выберите режим:

- `1` — введите название города;
- `2` — введите широту и долготу;
- `0` — завершите приложение.

Пример результата:

```text
Погода в Москва: 12.4°C, пасмурно
```

## Обработка ошибок и кэш

При сетевых ошибках, HTTP 429 и временных ошибках сервера приложение выполняет
до трёх повторов с паузами 1, 2 и 4 секунды. Последний успешный ответ
сохраняется в `weather_cache.json` вместе с городом, координатами и временем
получения. Если запрос не удался, приложение предложит показать кэш, когда
данным меньше трёх часов.

Если OpenWeather сообщает об отклонённом ключе (HTTP 401 или 403), проверьте,
что ключ без лишних символов указан в `API_KEY` файла `.env` и активирован для
используемых API.
